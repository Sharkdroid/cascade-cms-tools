Use this for a multi-step session (several templates combined, a novel
pattern, or anything that took real back-and-forth against the validator to
get right) — not for a single straightforward template usage.

Answer these three questions plainly. Extend with task-specific questions
where useful; don't drop these three.

## Did you find everything you needed when designing/implementing the script?

Name any field, method, or pattern you had to search for beyond
`templates/INDEX.md`, `references/operations_schema.json`, and
`references/asset_api.md`. If you ended up reading `cascade_cms/*.py`
directly, say what the schema/reference docs were missing.

## Did you need any workarounds?

Anything not directly covered by a template — a pattern reverse-engineered
from library source, a manual multi-step edit sequence, a case the validator
initially rejected and how it was resolved.

## How well did the skill's own scripts/tools help?

Whether `new_script.py`, `validate_script.py`, and (if connected) the MCP
server's schema tools actually caught problems early versus problems only
surfacing at the end, and whether any validator message was unclear.
